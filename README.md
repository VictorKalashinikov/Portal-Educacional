# 🎓 Portal Educacional

Um portal educacional desenvolvido para simular um ambiente acadêmico, reunindo funcionalidades que facilitam o acompanhamento da vida escolar dos estudantes.

O projeto apresenta uma interface intuitiva e organizada, permitindo consultar informações acadêmicas, acompanhar atividades e gerenciar o acesso à plataforma.

## 🚀 Funcionalidades

- **Página inicial:** painel com informações e destaques acadêmicos.
- **Gerenciamento de atividades:** adicionar, concluir e excluir tarefas escolares.
- **Notas:** consulta ao boletim e ao desempenho acadêmico.
- **Faltas:** acompanhamento da frequência escolar.
- **Horários:** visualização do quadro de horários das aulas.
- **Login e cadastro:** criação de contas e autenticação de usuários.
- **Gerenciamento de sessão:** identificação do usuário conectado.
- **Pesquisa inteligente:** busca de páginas e filtragem de informações nas tabelas.
- **Contato:** formulário para envio de mensagens.
- **Impressão:** funcionalidade para imprimir informações disponíveis.

## 🎯 Objetivo do projeto

O objetivo foi desenvolver uma aplicação web que simula um portal acadêmico, colocando em prática conhecimentos de desenvolvimento Front-end, manipulação do DOM, eventos JavaScript, armazenamento local de dados e organização de interfaces.

O projeto também proporciona experiência na construção de páginas interligadas e no desenvolvimento de funcionalidades interativas utilizando JavaScript puro.
